# Anatomy 内部可视化与 iPhone 尺寸参照

入口：index.html（深色）或 index-light.html（浅色）。HTML内已包含全部SVG、CSS与交互脚本，无须联网或npm安装即可打开。可直接在浏览器打开；配套GLB下载链接需要保留anatomy/与exports/的相对目录。完整压缩包是上一级 anatomy-viewer-v02.zip。

## 功能

- 分层拆解：49个实际CAD部件，按八组分类；滑块控制展示间距。
- 内部结构：隐藏面层、传感层和PET载膜，直接看九个dome、PCB轨、磁环与电池模块。仅改变可见性，不删除CAD特征。
- iPhone对比：键盘与iPhone16机身采用同一投影和毫米尺度。
- 点选图形或右侧部件表查看作用与尺寸；支持放大、放大后拖动、重置、明暗主题。
- 方向键、Home/End控制拆解，空格合拢/展开，Escape清除选择。
- 自动演示由按钮开启；离屏与页面隐藏时暂停，静止后停止帧循环；系统减少动态效果开启时直接到目标位置并禁用自动演示。

## 来源与实现

按用户指定使用 https://github.com/neekitalian/anatomy ，固定commit：1482e8469b0a9e0d8cc18ea2740a01423d29ae80。

实际使用其中iso-kit的等距投影、图卡与页面框架、CSS，以及lathe工具的光照向量与四阶明暗计算。对应MIT源码和许可证位于项目visual/vendor/anatomy/。没有使用其他Anatomy仓库替代此fork。

图形来自当前build123d CAD的真实表面三角网格（0.08 mm弦差、0.25 rad角度公差），不是重新画的体积方块。几何数据在cad-parts-v02.json，由checks/anatomy_data.py生成。visual/build.mjs构建独立HTML；显示单位mm，图卡投影将CAD的Y方向反射后重新计算面法线，保留开孔、支撑轨与点阵。

此适配器按层和真实Z坐标组织SVG绘制顺序，组内前向表面按深度排序。它是解释性SVG展示；使用的是CAD网格，不是Anatomy原生primitive/SDF绘图，因此没有运行或声称通过primitive版A.audit/settle全套几何审计。原版primitive审计不能直接证明这里的网格绘图和层间运动。不得把展示动画当成真实装配路径、连续碰撞验证或CAD拓扑校验。

## iPhone 参照的假设

- 机身选择iPhone16：71.6×147.6×7.8 mm，来源：[Apple技术规格](https://support.apple.com/en-gb/121029)。仅这三个机身尺寸使用公开规格。
- 圆角R11；相机岛19×34×2.5 mm、R9、中心X−23/Y51；镜片Ø11×0.3 mm、Y44/58，均为示意参数，不来自Apple工程图。
- 并排CAD模型的净距14 mm；SVG为排版另设间距，物体尺度保持一致。没有加入手机壳厚度。
- 贴背CAD示意将卡片中心向手机下方移12 mm。先前居中示意与示意相机有碰撞，已保留日志并纠正；未缩小键盘或相机以绕过检查。
- 下移后的模型在当前53部件、单一静止姿态下无体积重叠。因为相机和手机磁环位置不是工程数据，这不等于真机适配，更不等于MagSafe对中。
- 参照模型背面Z=0、机身前面Z=−7.8，键盘外表面Z=5.8；贴背总体外框厚13.6 mm。镜头突出包含在示意物体中，机身7.8不含额外镜头示意高。

## 检查记录

- CAD：贴背53部件静止干涉检查通过，阈值0.000001 mm³，无fit豁免，无未测量配对；原始报告phone-interference-v02.json。未校验动画拆装路径。
- 两个新增GLB在Blender5.3实际导入，均53网格；并排外框约145.6×147.6×13.6 mm，贴背71.6×147.6×13.6 mm，尺寸误差小于0.02 mm。原始报告glb-import-checks.json。
- 浏览器：深/浅色、分层/内部/比较、选取/取消/重置、方向键与End、放大/拖动/重置、390 px窄屏、减少动态效果均实测。测试控制台无异常、无横向溢出。
- 通过Anatomy capture/drive截图查看整体与4倍局部。检查图标、壳孔、PCB轨、磁环和dome显示；不是材料光学真实性测试。
- Anatomy lines检查输出0个浮动端点，但这里没有装饰性开放纹理线（0 of 0）；CAD轮廓线属于iso-edge，不在该检查范围。因此不能把这一输出宣传为整个网格线框已被几何审计。
- 单独的CAD干涉、STEP有效性和DFM结果仍见 ../phase-1/REVIEW-v02.md。树脂薄位检查失败、FDM与注塑警告没有因可视化而修复。
